# PharmaLabVR premium pharmaceutical laboratory platform

## Intent and audience
The human's latest scope is a fully functional, high-quality virtual pharmaceutical laboratory useful to pharmacy learners, pharmacists/expert users, instructors, researchers and universities. It is not restricted to a burette demonstration or a single class. It combines laboratory operation, deep scientific understanding, course authoring and reproducible research exploration. VR is primary; native Windows Desktop is a complete additional mode using the same authority. English and Arabic are first-class.

## Product decision
Create a modular pharmaceutical laboratory campus with one consistent premium workstation system and a broad expandable compound reference library. Build a genuinely complete first analytical bay, then add independently qualified stations/providers. All chemical compounds/all possible laboratory operations is the long-term breadth aspiration, not a finite verified capability or a universal solver promise. Never advertise unsupported compounds as simulated merely because their names exist. Every station/experiment reports what its model can predict and the evidence maturity.

The initial aqueous-six-research-v1 pack remains pinned and supported only within its original test matrix. The expanded catalog/roles/module roadmap below are authorized additions, not permission to feed unknown compounds into minteq. Molecular structures, pharmaceutical excipients, mixtures, solids, temperature-dependent behavior, kinetics and biological methods require separate representation and models; do not fake them through pH scripts.

## Four workspaces
Student: orientation, optional guided practice, predict-observe-explain-compare, scale reading, notebook and feedback.
Instructor: configure course/lesson from supported capabilities, demonstration, hint/rubric authoring and actual attempt review/export.
Researcher: supported open experiment, parameterized repeat runs, explicit model assumptions, notebook, compare plots and provenance-rich exports.
Expert/pharmacist: minimal guidance open station, compound/equipment search, quick context inspection and project workflow. This workspace is not a clinical treatment/dosing engine.

## Shared functional scope
Persistent room/bench/equipment; correct profile-derived scale; meaningful grab/mount/pour/measure/rinse/dispose; consequential spills/contamination; source-based chemistry/observations; clear unsupported/failure/hold states; pause/recenter/settings/help; durable sessions/history/review/forks/export. Compound library, instrument model registry and experiment packs are data-driven. Tasks/styles must work on real runtime paths and actual UI actions. No compulsory cloud account. Local versioned coursepacks and anonymous IDs support an institutional pilot without adding a cloud dependency.

## Release ladder
R1: premium fully operating analytical bay, supported six-stock free lab +two ungraded Research lessons, Arabic/English, durableReview, instrument reading and builds.
R2: verified catalog, concept-learning toolkit, complete teacher/research/expert workspaces and localcoursepacks.
R3: separately evidenced analytical/physical/organic/formulation/pharmacognosy/biochemical/microbiology station packs. Ship working packs incrementally; missing scientific data/device validation stays named pending. A room preview or lesson text alone is not a functional pack.
The commercial-quality demo can be prepared for supported R1/R2 capabilities. Experimental/calibration/device/participant gates cannot be erased by premium graphics. Final planner review checks exact artifacts and advertised scope; no automatic PRmerge.

## Architecture and non-negotiable pins
Unity6000.3.25f1, URP, OpenXR, XRI3.3.2, C++17 native authority, pinned IPhreeqc/minteq initialpack. Reuse repository pins; no unrequested engine/package upgrade. One authority performs mutations; immutable observations carry dependency/model identities. World-space uGUI+TMP for VR and screen-space companion views from shared viewmodels; no new web app or vendorSDK requirement. Original numeric/material/thread/budget/limit/persistence contracts remain intact. Provenanced provider registry extends capabilities without silent fallback.

## Scope decisions and alternatives
Chosen: physical laboratory + restrained contextual panels. A dashboard-first interface would obscure manual technique; hyperreal cinematic rendering would consume headset budget without improving readings. Use editor-generated analytic apparatus plus deliberate room/material design, then measure PC/mobile settings. Explanations are deterministic/source-backed model evidence; an LLM is not required or authorized as chemical authority. Cloud collaboration/LMS/SSO/purchases and new clinical applications are future separate scopes, not initial blockers.


## v2 product-value refinement
Primary audience for the first usable release is pharmacy students and instructors. Complete the useful learner/instructor/expert journeys specified in13 before new science providers. A broad catalog and every future station are not prerequisites for this release. This priority preserves the whole roadmap while preventing another collection of partial foundations. Demand, adoption and willingness to pay are untested; participant evidence is planned, never fabricated.
