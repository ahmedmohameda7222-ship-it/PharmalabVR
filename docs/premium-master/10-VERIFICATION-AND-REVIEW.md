Each advertised station/compound/experiment has a complete provider-backed or explicitly reference-dataset journey. Record numerical evidence, bounds, unit/phase consistency, bilingual interaction and performance. Pending data packs remain pending and outside simulated coverage. ## Exact build evidence
Build/testing tools are those in original07 and repository scripts. Record actual commands/results/versions/codeSHA/settings/mode/model/workload. Available clean native/Unity regressions and Player builds required. CI native success is not Unity/VR/human acceptance. Artifact hashes confirm bytes, not scientific accuracy. Final evidence may be a later docs-only SHA; manifest must link it to the exact functional SHA.

## Planner handoff
Latest HEAD and diff, complete task ledger, original95 + expanded coverage, actual screenshots/recording/journeys, tests and failures, artifact manifests, limits and named remaining gates. Implementation cannot grant AcceptedPlanner itself or merge PR. Planner inspects actual source/build/evidence and returns changes or explicit acceptance. A task ledger cannot prove a feature without its referenced evidence.
