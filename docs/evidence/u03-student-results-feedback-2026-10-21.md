# U03/U05 — student results, staff submission preview and append-only feedback

**21 October 2026. Code-first source; no real human/browser/Unity run.**

## Server authority
The live schema already has RLS SELECT policies for `submissions`, `grades`, `feedback`, restricting students to owned submissions, approved grades and explicitly visible feedback. The audited `public.university_record_feedback` RPC is preexisting and immutable/append-only, requiring actual active instructor/admin membership and section assignment, not an unsafe client claim. No production migrations/functions or data were changed in this campaign.

## New browser-source increment
`portal/src/api.mjs`: `studentResults` refetches selected published assignment under Auth/JWT and RLS, requests own submissions then released grades/feedback with tenant/submission filters, validates returned parent identity and refuses draft/private/cross-tenant data; `staffSubmissions` lists at most first 100 RLS-visible section submissions, even for TA read-only; `staffRecordFeedback` posts the existing authorized RPC with current student release flag and exact request ID, accepts only a canonical feedback UUID. Score numeric(8,3) checks use a three-decimal numeric round-trip rather than exact IEEE-754 multiplication.

`portal/src/view.mjs` is DOM-text-only. Student sees a published assignment's available approved score and released notes; instructor/TA sees section submission preview; only assigned instructor/admin has a feedback author affordance. Form's student-release checkbox starts unchecked (private). `portal/app.mjs` preserves active institution/student/section identity for async state, clears stale content on role change/signout, and retains an unchanged draft's idempotency UUID after timeout. All Native evidence remains unverified and no grade approval client is added.
