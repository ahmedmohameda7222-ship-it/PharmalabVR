## Shared Native-first interaction

- **Wheel:** `DesktopWheelRouting` routes non-UI scroll exclusively: if `DesktopInputAdapter.HasHeldTool`, tool moves along actual `labFrame.up` ±0.02m/notch with per-frame delta clamp. Otherwise `DesktopCameraController` modifies local camera fieldOfView only (35–85°); it never translates apparatus. The camera is explicitly configured with the same adapter AFTER `BuildPipelineEntry.CreateLabScene` parents and rotates the camera. This addresses `AddComponent` invoking `Awake` before parenting and fixes the first right-drag resetting the authored 30° pitch.
- **Tilt and camera:** Q/E rotates only the held tool around lab-forward. WASD translates the Desktop camera, right-drag rotates the camera; when the pointer is over uGUI/EventSystem or the actual Desktop HUD these world inputs do not fire. Arrow keys/PageUp/PageDown remain separate world tool manipulation. Esc is checked before F pick/manipulation and submits actual Native Pause via `SessionController`. Pause/Hold disables further world mutation.
- **Valve vs plane drag:** `DesktopPointerRouting` owns left-press exclusively: plain held left-drag adjusts Native-bound burette actuator; Shift + left-drag moves held research tool along a world-space plane through its prior pose, preserving the first ray-plane offset to avoid teleport. UI focus, empty hand and disabled input yield neutral; release or drag zeros the old actuator, never faking a material receipt. Shift+left can never also actuate the valve.
- **F Place:** `DesktopInputAdapter.TryPlaceHeldTool` uses `Physics.RaycastAll`, selects closest non-self collider (not enumeration order), and accepts only the generated physical `BenchSurface` in the same Lab tree with a bounded nonnegative vertical gap ≤0.20m and upright dot ≥0.95. On refusal tool ownership, Rigidbody and pose stay untouched; on acceptance root aligns to actual collider surface and releases its kinematic Rigidbody. These are conservative, uncalibrated research bounds. Actual scene/Player collision/hardware proof remains deferred.
- **Burette physical outlet:** Generated `DesktopResearchTool` previously lacked `OutletExit`; `LabCaptureTarget.Estimate` would see no valid receiving geometry regardless of stock chemistry. `ResearchOutletGeometry.BottomLocalY` now derives marker Y from the scene's actual cylinder mesh lower bound, scale and offset, not a stock bottle/pipette position; generated scene anchors the outlet accordingly. No change to Native material authority or chemical budgets.
- Desktop HUD now lists the actual supported gesture mapping; full accessibility/RTL assets, screenshot legibility and Desktop orientation acceptance remain separate P10.02/P10.03 work.
