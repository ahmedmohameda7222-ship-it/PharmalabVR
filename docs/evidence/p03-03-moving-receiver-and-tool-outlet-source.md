## Verified source and boundaries

- Real `LabCaptureTarget.Estimate` uses actual `OutletExit` and receiver aperture, finite upright/downward/outlet offsets. A new shared pure C# `CaptureAdmission.MayCapture` adds explicit moving receiver exclusion at **0.02 m/s** (conservative Research motion bound, not experimental calibration); positive height within max fall, radius, outlet down/receiver upright, and finite numeric inputs. Native owns capture fractions, committed parcels and chemistry.
- `ReceiverMotionTracker.Observe(frame,time,worldPosition)` computes per-frame speed, caches the velocity for duplicate XR/desktop samples in the same Unity frame and fails closed on NaN, nonmonotonic frame or time; `LabCaptureTarget.Estimate` compares this **kinematic world-transform movement** against the research bound as well as `Rigidbody.linearVelocity` when present. This covers moving XRI-held receiver transforms that can report zero Rigidbody speed; correct hardware tracking still must be verified.
- `BuildLabAssets.GenerateResearchPipette` adds a direct `OutletExit` anchored to **mesh bottom of MeteredOutletTip**, not an unrelated burette coordinate; `GenerateResearchStockBottle` adds its own outlet anchored to **NarrowNeck top**, direction upward while the bottle is upright/capped. Neither adds an artificial continuous fluid model or calibrated pouring.
- The two research tool prefabs now receive a kinematic `Rigidbody`, their existing enabled child collider and a real `XRGrabInteractable`. The burette valve and tool IDs remain separate; grab is physical presentation only until XR/Native input ownership can be executed in Unity.
- Existing product `ResearchInstrumentPayloads` now exposes a **presentation-only** `CanDispensePipette(nativeTipVolume, requestedVolume)` matching Native synthetic 0.10 ml retained tip. First aspiration of 0.05 ml **cannot** dispense 0.05 ml. The shared `LabPanelController` blocks that premature command, `SessionController` reads actual Native tip snapshot, and Desktop and VR labels/availability reflect the requirement to accumulate at least 0.15 ml tip for a 0.05 ml dispense; scientific transport budget still may require multiple input windows. Native remains authoritative. Package instrument profile now documents 1e-7 m3 research hold-up.
